Geometry for structures

Frames on a grid only need points and lines. Roofs, arches and shells need curves and surfaces. Three sessions give you the geometry a structural engineer is usually asked to generate.

{{sn}}Curves and how to divide them

By the end you can place nodes along any curve and you know what "equal division" really means.

Idea

Every curve has a parameter, t, that runs from its start to its end, a little like a kilometre post along a road. Evaluate Curve returns the point at a given t. Right-click a curve input and choose Reparameterize to make t run from 0 to 1, so 0.5 is roughly the middle.

For structures the workhorse is Divide Curve. It cuts a curve into N pieces of equal length along the curve and returns N + 1 points. On a straight chord that means equal spacing. On an arch it does not: the points are evenly spaced along the arc, so their spacing on plan is uneven.

In Rhino: a parabolic arch

A parabola carries uniform load in pure compression, which is why arch bridges use it. Its shape is z = 4 f x (L − x) / L².

  1. Make the x values with Range: domain 0 to L, 20 steps.
  2. Place Expression. Zoom in on it to add inputs and name them x, L and f. Double-click it and type 4*f*x*(L-x)/L^2.
  3. Send x and the result into the X and Z of Construct Point, then the points into Interpolate.
  4. Divide the arch with Divide Curve. For hangers at equal spacing on the deck instead, divide the deck line and send those x values through the same Expression.

{{sn}}Vectors and moving things

By the end you can copy a truss along a building to make a roof, with every truss kept in its own branch.

Idea

A vector is a direction with a length. Unit X, Unit Y and Unit Z make a vector along an axis, and their input F sets its length. Move shifts geometry by a vector. Loads are vectors too: a 10 kN load downwards is the vector (0, 0, −10).

Move with one truss and a list of vectors is where lists and trees meet. The truss is a list of lines. The vectors are a list as well. Wire them in plainly and Longest List pairs line 0 with vector 0, line 1 with vector 1, and tears the truss apart. Graft the vectors and each one runs separately against the whole truss.

{{sn}}Surfaces and grids on them

By the end you can turn a roof surface into a grid of members, including a diagrid.

Idea

A surface has two directions, called U and V, the way a curve has one parameter t. Divide Surface returns a grid of points on it as a tree: one branch per U position, each holding the points along V. From there it is the list work you already know.

  • Lines along V: within each branch, node j to node j + 1.
  • Lines along U: Flip Matrix first, then the same.
  • Diagrid: connect node (i, j) to node (i + 1, j + 1), and node (i + 1, j) to node (i, j + 1). That is one branch shifted against the next.

Try it here

In Rhino

  1. Build the arc from Session {{n:s13}} and extrude it with Extrude (Surface, Freeform) along a Unit Y vector.
  2. Add Divide Surface (Surface, Util) with sliders on U and V. Put a Param Viewer on P.
  3. Draw the V lines and the U lines as two separate groups.
  4. For the diagrid, pair each branch with the next one. Shift Paths or Relative Item (both under Sets, Tree) can do it. The simpler route to start with is Flip Matrix, then Shift List inside each branch.

When the surface comes from an architect it will not be a neat extrusion. Reference it from Rhino as in Session {{n:s6}} and the rest of the definition stays the same.
